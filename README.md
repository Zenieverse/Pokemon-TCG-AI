---

### 🚀 Key Features

- **⚔️ Live Arena & Battle Simulator**: Full turn-by-turn state machine managing Active & Bench positions, energy acceleration, stage evolution, trainer card execution, and prize card race mechanics.
- **🌳 Information-Set MCTS Explorer**: Visualizes rollout trees, UCT node selections ($Q + c \sqrt{\ln N / n}$), win probabilities, and expected prize differentials.
- **🔮 Bayesian Belief Engine**: Real-time hypergeometric distribution radar calculating opponent hidden-hand risks (e.g., *Boss's Orders*, *Iono*, *Rare Candy*).
- **🧪 Meta Deck Lab & Monte Carlo Engine**: 5,000-hand opening consistency simulations across Tier-1 archetypes (*Charizard ex*, *Gardevoir ex*, *Pikachu ex*, *Miraidon ex*) with complete matchup matrix heatmaps.
- **🧠 Gemini 3.7 Flash AI Strategist**: Real-time Grandmaster tactical co-pilot providing turn-by-turn strategy evaluations, threat assessments, and prize trade recommendations.
- **🔊 Synthesized Web Audio Effects**: Zero-dependency Web Audio synthesizer providing reactive sound cues for attacks, evolutions, energy attachments, and knockouts.
